# 知识库下一程：场景与路线（2026-09 立项）

> 结论：知识库从「一次生成的分析产物集合」转向「贯穿阅读时刻的动线设施」。
> 形态跟着「时刻」走，不跟着「图表类型」走。本文档是 M1–M3 的裁定依据，动手前先读。

## 一、人格与时刻

| 人格 | 典型时刻 | 真实问题 | 现有覆盖 |
|---|---|---|---|
| 网文追更读者（主力） | 连载新章更新时 | 三分钟找回状态（主角在干嘛、和谁一伙） | 人物图谱部分覆盖；情节线空白 |
| 同上 · 重读 | 想看重头戏 | 高潮在哪一章，直接跳 | 空白 → M1 节拍结构条 |
| 技术文档读者 | 拿到陌生 SDK/协议文档 | 我从哪进入？完成任务经过哪几步？ | 空白 → M3 接口调用图 |
| 同上 · 照着做 | 读教程/手册 | 第一步干嘛、条件分支走哪边 | 空白 → M3 方法流程图 |
| 学术读者（存量人格） | 读前分流 | 这篇值不值得精读 | 论文速览卡 ✓ |
| 同上 · 读中 | 概念/方法不懂 | 术语定义、方法 pipeline | 术语卡/概念图谱 ✓、流程图 M3 |
| 同上 · 读后 | 文献综述 | 十篇摆一张桌上比较 | **空白**（方向题，Atlas 为地基，本期不做） |

判据（开工前可自查）：馆藏文本书 vs 技术类 PDF 占比；速览卡/术语卡生成量；上线后看**回原文点击率**与**增量补充触发率**。

## 二、路线

### M1 全书骨架 digest + 叙事节拍结构条（本里程碑）

- **digest 基建**（零 API 成本的全本视野）：每章 = 标题 + 首尾逐字摘句 + 字数，总预算定死（≈7.6k 字）；超长书确定性等距采样（保首尾章）。证据摘句取自骨架原文 = 逐字可定位，回原文链路不受损。
- **节拍任务**：单块语料（digest 即唯一 chunk），注册表形状不变；一次调用产出全书节拍（开局/引子/推进/转折/中点/低谷/高潮/结局），去黑话词汇，术语降级为侧卡补充。
- **结构条落点在目录页**：目录折叠后读者丢失全局结构感，节拍尺补回来——点节拍直达该章。知识库卡片保留完整查看器入口。
- 验证信号：节拍点击率、回原文点击率。

### M2 情节脉络线

泳道时间轴（每条情节线一行，域色板取色）+「你在这里」游标（readingProgress 现成）+ 增量补充原生（连载每周长新章，快照式产物两周报废）+ 章末卡片动线接入；digest 注入分块提示词当全书上下文，稳线归属。

### M3 技术文档双卡 + 学术词汇微调

- 方法流程图：分层 DAG 布局（最长路径分层 + 重心序，纯函数）；操作步骤/论证链/请求管线。
- 接口调用图：复用图谱机械（节点=接口、边=调用），加方向箭头；**别名归并关**（getUser ⊄ getUserById），knownNames 开（治标识符漂移）；文案诚实限定「文中出现的调用关系」——文档不是源码，不承诺完整性。
- 学术微调：速览卡提示词按报告体换词汇（核心判断/依据/风险），**不拆新卡**（防子类型碎片化）。

### 方向题（下一阶段）

读后跨篇比较（综述矩阵/多报告对读），Atlas 为地基；等 M1 验证信号出来再立项。

## 三、护栏（不做什么）

1. 不为文档子类型拆专属卡；
2. 不承诺图谱完整性（覆盖率对账 + 限定词代替）;
3. 不动跨篇比较；
4. 验证信号出来前不给节拍条加编辑/拖拽交互。

## 四、每期固定携带「信任四件套」

回原文跳转 · 覆盖率对账 · 修订模式 · Markdown 导出——相对通用 AI 工具的唯一差异化，验收项而非后续补课。
