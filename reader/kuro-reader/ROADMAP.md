## 一、定位与规划原则

**产品定位**：本地优先 + NAS 自托管的漫画与文字统一阅读器。差异化来自「隐私、一个应用读所有本地内容、连接自己的存储」，不与云端阅读平台（微信读书等）和在线书源工具（Legado 等）竞争。
**定位升级（2026-08-30）**：在阅读器之上叠加「手记采集器官」战略——划线/批注/检索/导出/回望做到极致，经 Markdown 导出嫁接 Obsidian/Notion 等外部知识库；应用内不做双链/笔记图谱/跨书全文检索（见「明确不做」）。

**排序原则**：
1. **信任优先于功能**——会丢数据的问题（备份缺失、进度易失）先于一切新功能
2. **闭环优先于广度**——已承诺但断头的链路（云端导入、cloudSync）先于新格式新协议
3. **小工作量 × 高感知优先**——交互打磨项集中清理，性价比最高
4. **保持定位纪律**——见「明确不做」清单

## 三、明确不做（定位纪律）

| 不做 | 理由 |
|------|------|
| 在线书源/网站爬虫 | 法律灰色地带，Legado 已占据该心智；与隐私定位冲突 |
| 账号体系与社交功能 | 与本地优先定位根本冲突，且服务端成本高 |
| DRM 内容支持 | 不可行也不必要 |
| AI 摘要/翻译 | 列为观察项，待采集器官价值验证后评估 |
| 双链/笔记图谱/跨书全文检索 | 采集器官战略边界：知识组织交给 Obsidian/Notion（应用内手记级检索/筛选已交付） |

## 四、北极星验收标准（v1.1 发布门槛）

1. **全旅程无断点**：一本书从 NAS（WebDAV/OPDS）→ 导入 → 阅读 → 批注 → 导出笔记，每一步都在应用内完成
2. **三类内容统一**：漫画 / 文字 / PDF 共享同一套进度、批注、书签体验
3. **数据零丢失**：备份 → 恢复 → 换设备，书籍、进度、批注、书签、设置全部完整
4. **移动端无别扭**：Android 真机返回键、单击响应、单手可达性符合平台习惯
