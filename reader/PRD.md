# Kuro Reader - 产品需求文档 (PRD)

## 1. 项目概述

### 1.1 产品定位
Kuro Reader 是一款主打本地阅读的高级漫画阅读 App，核心设计理念是「纸质模式（Paper Mode）」——通过模拟真实纸张的质感、色调与阅读体验，为用户提供极致沉浸、如同阅读实体书般的数字体验。

### 1.2 目标用户
- 追求高品质阅读体验的漫画爱好者
- 重视视觉舒适度和护眼功能的用户
- 拥有本地漫画资源库，需要专业管理工具的用户
- 偏好极简、优雅设计风格的用户

### 1.3 核心价值主张
- **纸质模式**：模拟真实纸张纹理和色调，减少数字疲劳
- **全渠道导入**：支持本地文件、云端网盘、无线传输等多种导入方式
- **沉浸式阅读**：全屏阅读器，极简 UI，专注内容
- **本地优先**：数据存储在本地，保护隐私，支持离线阅读
- **隐私保护**：无传统登录，可选手势密码/生物识别认证保护书库内容

## 2. 设计规范

### 2.1 品牌色彩

系统包含两套配色体系：

| 模式 | 背景色 | 主色（墨迹） | 辅助灰 | 风格 |
|------|--------|-------------|--------|------|
| **Paper Mode（纸质模式）** | `#FDF8F8` 暖米白 | `#000000` 纯黑 | `#DDD9D9` 冷灰 | 温暖、文学感、纸质印刷 |
| **Dark Mode（深色模式）** | `#131313` 深黑 | `#D0BCFF` 淡紫 | `#494454` 暗灰 | 现代、玻璃拟态、科技感 |

### 2.2 字体系统

| 用途 | 字体 | 风格 |
|------|------|------|
| 标题/展示文字 | **Playfair Display** (Serif) | 文学感、高级感、编辑风格 |
| 正文/长文本 | **Literata** (Serif) | 数字阅读优化，模拟经典书籍字体 |
| 标签/导航/UI | **Inter** (Sans-Serif) | 现代、清晰、功能性 |

### 2.3 核心质感

- **纸张颗粒纹理**：全局覆盖 SVG noise filter（2-5% opacity），模拟未涂布纸触感
- **零阴影原则**：不使用 box-shadow，深度通过色调层和 1px 细边框传达
- **圆角规范**：统一 `0.25rem` (4px) ~ `0.5rem` (8px)
- **布局网格**：最大内容宽度 720px，桌面端边距 120px，移动端 24px，8px 基准网格

## 3. 功能模块

### 3.1 首页（Home）

**功能定位**：用户进入 App 后的主入口，展示继续阅读和收藏内容。

**核心元素**：
- **顶部导航栏（TopAppBar）**：左侧用户头像、中间品牌 Logo「Kuro Reader」、右侧搜索按钮
- **继续阅读区**：大幅横向卡片，展示当前阅读漫画的封面、标题、当前章节、阅读进度条（百分比）
- **我的收藏区**：网格布局（2列移动端 / 3列桌面端），漫画封面 + 标题 + 更新状态
- **底部导航栏（BottomNavBar）**：浮动胶囊样式，包含「首页」「书库」「导入」「设置」四个入口

### 3.2 漫画详情页（Comic Detail）

**功能定位**：展示单部漫画的详细信息和章节列表。

**核心元素**：
- **返回导航 + 更多操作**
- **Hero 区域**：漫画封面大图 + 标题 + 作者 + 标签（类型/评分）+ 简介 + 「立即阅读」主按钮 + 「收藏」按钮
- **章节列表**：网格/列表展示所有章节，标记已读/未读/当前阅读状态
- **排序功能**：支持章节排序切换
- **展开全部**：长列表的展开收起

### 3.3 沉浸式阅读器（Immersive Reader）

**功能定位**：核心阅读场景，极致减少 UI 干扰。

**核心元素**：
- **全屏漫画展示**：支持纵向滚动（条漫模式）和横向翻页（单页/双页模式）
- **浮动控制层**（点击屏幕唤出/隐藏）：
  - **顶部**：返回、章节标题、收藏、更多
  - **底部**：进度滑块（当前页/总页数）、阅读方向切换（纵向/横向）、翻页按钮
- **纸质纹理叠加**：阅读区域带有纸张颗粒感
- **图片处理**：灰度化 + 暖色 sepia 滤镜 + 对比度增强，模拟印刷效果

### 3.4 导入中心（Import Center）

**功能定位**：从多种渠道导入书籍资源到本地书库。

**核心元素**：
- **云端网盘**：百度网盘、Google Drive、OneDrive、自定义来源
- **无线传输（WiFi 传书）**：开关控制、内网地址展示、一键复制
- **本地导入**：扫描本地文件、系统文件选择器，支持 ZIP/RAR/CBZ/CBR 格式
- **自定义云端来源配置**：支持 WebDAV / SMB / FTP / OneDrive 协议

### 3.5 设置页（Settings）

**功能定位**：用户个性化配置和系统管理。

**核心元素**：
- **阅读偏好**：
  - Paper Mode 开关（模拟电子墨水屏）
  - 翻页手势开关
  - 阅读方向设置（从右至左 / 从左至右）
  - 排版与字体设置
  - 纹理强度滑块
- **存储与同步**：
  - 云同步开关（跨设备同步进度）
  - 清除本地缓存（显示已用空间）
  - 存储管理（显示已用/总空间）
- **账户管理**：
  - 管理个人资料（本地昵称、头像，无需注册账号）
  - 应用锁设置（启用/禁用认证、修改手势密码、注册生物识别）
  - 清除所有数据（重置 App）

### 3.6 阅读统计（Reading Stats）

**功能定位**：数据可视化，增强用户成就感与留存。

**核心元素**：
- **Bento Grid 统计卡片**：
  - 累计阅读时长（小时）
  - 当前连续阅读天数（Streak）
- **已完成作品列表**：书名 + 作者 + 类型标签
- **近期阅读趋势图**：柱状图展示近7天阅读时长

### 3.7 批量管理（Batch Management）

**功能定位**：高效管理书库内容。

**核心元素**：
- **批量选择模式**：封面左上角自定义复选框，支持多选
- **选中状态视觉反馈**：边框高亮 + 遮罩层
- **底部浮动操作栏**：删除、移动、标为已读
- **全选/取消操作**

### 3.8 个人资料页（Profile）

**功能定位**：用户身份展示与快捷功能入口。

**核心元素**：
- **用户身份区**：头像、用户名、等级称号（如「Kuro Scholar」）、注册时间
- **本地存储进度条**：已用空间 / 总空间 + 剩余可存数量估算
- **功能 Bento Grid**：
  - 离线缓存管理
  - 我的评价（数量）
  - 意见反馈
  - 关于 Kuro Reader（版本号）

### 3.9 书架（Library）

**功能定位**：书库的主入口页面，当用户没有收藏任何漫画时展示空状态引导。

**核心元素**：
- **顶部导航栏**：用户头像 + 品牌 Logo + 搜索按钮
- **空状态容器**（居中展示）：
  - **插画区**：极简线条风格插画（阅读椅/打开的书），单色墨水风格
  - **标题**：「书架空空如也」
  - **引导文案**：「开启你的第一次沉浸阅读，从导入书籍开始。」
  - **操作按钮**：「立即导入」+ 「去搜索发现」
- **底部导航栏**：与首页一致的浮动胶囊导航

### 3.10 搜索与发现（Search & Discover）

**功能定位**：书库/发现页面的内容浏览入口，提供搜索功能和编辑推荐内容。

**核心元素**：
- **搜索输入区**：全宽搜索框，带搜索图标，底部边框样式
- **热门关键词（Trending Keywords）**：标签云形式展示热门搜索词
- **发现 Feed（Discovery Feed）**：
  - 编辑推荐卡片列表（纵向排列）
  - 卡片结构：左侧封面图 + 右侧信息区
  - 信息区：分类标签 + 标题 + 简介（3行截断）+ 操作入口

### 3.11 应用锁与认证（App Lock）

**功能定位**：保护用户隐私，防止他人未经授权访问书库内容。不采用传统账号密码登录，而是使用本地认证方式。

**认证方式**（按优先级）：

| 优先级 | 认证方式 | 说明 | 平台支持 |
|--------|---------|------|---------|
| 1 | **系统生物识别** | Face ID / Touch ID / 指纹 | iOS / Android |
| 2 | **系统 PIN/密码** | 设备锁屏密码 | iOS / Android |
| 3 | **手势密码** | 3×3 九宫格图案解锁 | 全平台 |

**手势密码界面**（kuro_reader_14）：
- **品牌标识区**：App 图标 + 「Kuro Reader」标题 + 「请输入手势密码」提示
- **3×3 九宫格**：
  - 圆点默认状态：小圆点，bg-surface-tint，opacity-30
  - 选中状态：大圆点（14px），bg-primary，ring 高亮，scale-110
  - 连线：SVG line，stroke-primary，stroke-width-2，连接已选中的点
  - 交互：touch 拖拽选择，支持手指滑动经过自动选中
- **底部操作**：「忘记手势？」+ 「切换账号」（实际为切换认证方式）

**设置项**（在设置页中）：
- **应用锁开关**：启用/禁用认证
- **认证方式选择**：自动（优先生物识别）/ 手势密码 / 系统认证
- **修改手势密码**：验证旧密码 → 设置新密码（至少连接 4 个点）
- **生物识别注册**：调用系统 API 注册指纹/面容

**触发场景**：
- App 从后台切回前台（超过设定时间，默认 5 分钟）
- 首次启动 App（可选，默认关闭）
- 手动锁定（设置中提供「立即锁定」按钮）
- 设备锁屏后解锁（与系统同步，可选）

**认证降级策略**：
- 首选「自动」模式时：先尝试生物识别 → 失败后降级到系统 PIN → 最后降级到手势密码
- 生物识别不可用时（设备不支持/用户未录入）：自动切换到手势密码
- 手势密码连续错误 5 次：锁定 30 秒，提示"忘记手势？"
- 手势密码连续错误 10 次：要求输入系统 PIN 或重启 App

**安全策略**：
- 手势密码使用 SHA-256 哈希存储（不存明文）
- 连续 5 次错误锁定 30 秒，10 次错误需重启 App
- 生物识别失败自动降级到手势密码

## 4. 全局组件规范

### 4.1 导航体系

| 组件 | 移动端 | 桌面端 |
|------|--------|--------|
| **TopAppBar** | 简化版（返回 + 更多 或 头像 + Logo + 搜索） | 完整版（头像 + Logo + 导航链接 + 搜索） |
| **BottomNavBar** | 浮动胶囊，居中悬浮于底部，4个入口 | 隐藏，改为左侧固定导航栏或顶部导航链接 |

**导航入口统一**：首页、书库、导入、设置

### 4.2 按钮规范

- **Primary Button**：实心黑色背景 + 白色文字，hover 变深
- **Secondary Button**：1px 边框 + 无填充，hover 背景变浅灰
- **Icon Button**：圆形 hover 背景，无文字

### 4.3 卡片规范

- 无阴影，通过 1px `#EAE4E4` 边框或背景色差异定义边界
- 背景与页面背景保持一致或略深（surface-container）
- hover 状态：背景色微变或下划线

### 4.4 输入框规范

- 极简下划线样式（bottom-border only）
- focus 状态：边框变黑、略微加粗
- 无默认 focus ring

### 4.5 切换开关（Toggle）

- 自定义样式，圆形滑块
- 开启状态：黑色填充 + 白色圆点
- 关闭状态：灰色背景

## 5. 交互与动效

### 5.1 核心交互原则

- **calm pace**：全屏转场使用淡入淡出，避免滑动
- **active:scale-95**：按钮点击时有轻微缩放反馈
- **hover 过渡**：所有交互元素统一 `transition-colors duration-200`
- **图片 hover**：收藏封面 hover 时轻微放大（`scale-105`）+ 过渡动画

### 5.2 阅读器手势

- **点击屏幕中央/边缘**：唤出/隐藏控制 UI
- **纵向模式**：上下滑动滚动
- **横向模式**：左右滑动翻页 / 点击左右区域翻页
- **进度滑块**：拖拽跳转

## 6. 技术实现要点

### 6.1 响应式断点

- **移动端**：`< 768px`，边距 24px，单列/双列网格
- **桌面端**：`>= 768px`，边距 120px，最大内容宽 720px，三列网格

### 6.2 文件格式支持

- 本地导入支持：**ZIP, RAR, CBZ, CBR**
- 云端协议支持：**WebDAV, SMB, FTP, OneDrive API**

### 6.3 性能与体验

- 全局纸张纹理使用 SVG noise filter，避免大图资源加载
- 阅读器图片处理使用 CSS filter（grayscale, sepia, contrast）
- 支持暗黑模式切换（`darkMode: "class"`）
