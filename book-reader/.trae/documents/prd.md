## 1. 产品概述

墨韵(MoYun)是一款跨端本地电子书阅读器，以"沉浸式氛围阅读"为核心理念，通过动态氛围背景、段落聚焦、墨迹进度等独创功能，打造有别于传统阅读器的沉浸式阅读体验。支持 EPUB/TXT 格式书籍的本地导入与智能识别，提供如同翻阅纸质书般的温度与仪式感。

- 目标用户：追求阅读品质的文学爱好者、深度阅读人群
- 核心价值：让数字阅读拥有纸质书的温度与沉浸感，重新定义"读书"的体验

## 2. 核心功能

### 2.1 用户角色
无角色区分，所有功能对单用户开放，数据存储于本地。

### 2.2 功能模块
1. **书架页**: 书籍展示、导入入口、阅读统计概览
2. **阅读页**: 沉浸式阅读核心、氛围模式、专注模式、标注系统
3. **书籍详情页**: 书籍元数据、阅读进度、标注列表
4. **设置页**: 阅读偏好、字体主题、氛围模式配置

## 3. 核心流程

用户打开应用后进入书架页，书架背景根据当前时间呈现对应的氛围(晨曦暖橙、午后柔白、暮色深蓝、深夜墨黑)。若有最近阅读的书籍，书架顶部展示"继续阅读"入口，显示书名和阅读进度，点击直接跳转到上次阅读位置。用户点击导入按钮从本地选择书籍文件，系统自动解析格式并提取元数据(书名、作者、封面)。导入完成后书籍以书脊形式出现在书架上。点击书籍进入阅读页，阅读页同样具有氛围背景，用户可开启专注模式进行深度阅读，也可添加标注和笔记。阅读过程中实时记录阅读位置(章节+CFI定位)，退出时自动保存进度，下次打开从上次位置继续。阅读进度以墨迹晕染效果实时展示。

## 4. 用户界面设计

### 4.1 设计风格

- **设计理念**: "墨韵" - 传统水墨美学与现代极简设计的融合，追求"留白即内容"的东方意境
- **主色调**: 墨黑(#1a1a2e) + 宣纸白(#f5f0e8) + 朱砂红(#c23616)作为点缀
- **辅助色**: 暮蓝(#16213e)、暖琥珀(#e8a87c)、月白(#d4d4dc)
- **按钮风格**: 圆角微弧，轻投影，hover时有墨晕扩散效果
- **字体方案**: 阅读正文使用 Noto Serif SC(衬线)，UI界面使用 Noto Sans SC(无衬线)
- **布局风格**: 大量留白，卡片式布局，书架采用横向书脊排列
- **图标风格**: Lucide 线性图标，与整体极简风格统一
- **动效风格**: 缓入缓出，模拟墨水晕染和纸张翻动的物理质感

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|---------|---------|--------|
| 书架页 | 氛围书架 | 深色渐变背景+微妙噪点纹理，书脊纵向排列(高度统一、宽度按书页数比例)，当前时段氛围色调覆盖层 |
| 书架页 | 继续阅读卡片 | 书架顶部横向卡片，左侧封面缩略图+右侧书名/进度百分比/上次阅读时间，带墨迹进度条，点击进入上次阅读位置 |
| 书架页 | 导入入口 | 右下角浮动按钮，朱砂红色，点击后展开文件选择器 |
| 书架页 | 统计卡片 | 半透明毛玻璃卡片，展示阅读数据，带微光边框 |
| 阅读页 | 氛围阅读 | 全屏沉浸，顶部/底部工具栏自动隐藏，背景为宣纸纹理+氛围色调渐变 |
| 阅读页 | 专注模式 | 当前段落 opacity:1，前后段落渐变至 opacity:0.15，过渡动画 600ms |
| 阅读页 | 墨迹进度 | 底部细长条，已读部分以墨水晕染效果填充，未读部分为淡色纸纹 |
| 阅读页 | 标注系统 | 选中文字后弹出四色圆点选择器+笔记输入框，高亮以半透明色带覆盖 |
| 书籍详情页 | 元数据展示 | 封面大图+右侧信息列，背景模糊处理封面作为氛围底图 |
| 设置页 | 偏好配置 | 分组卡片式，滑块控件调节参数，实时预览效果 |

### 4.3 响应式设计

- 桌面优先设计，移动端自适应
- 书架页：桌面端多列书脊排列，移动端单列横向滚动
- 阅读页：桌面端固定最大阅读宽度(680px)居中，移动端全宽自适应
- 触控优化：阅读页支持左右滑动翻页，长按选中文字，双击进入/退出专注模式
- 工具栏：桌面端悬浮侧边，移动端底部弹出
