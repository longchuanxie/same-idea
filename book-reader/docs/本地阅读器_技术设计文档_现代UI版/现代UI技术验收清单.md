# 现代 UI 版技术验收清单

用于 LLM Agent 和 QA Agent 检查实现是否符合最新 V4 Modern UI 与技术设计。

---

## 1. 最新 UI 基准

- [ ] 使用 V4 Modern UI 作为最新 UI 基准。
- [ ] 未回退到旧版复古纸感主视觉。
- [ ] 首页为 Bento 式阅读工作台。
- [ ] 书架为分区分页结构。
- [ ] 搜索支持 Command Search 思路。
- [ ] Reader Toolbar 为现代浮层。
- [ ] 支持日间主题。
- [ ] 支持夜读主题。
- [ ] 支持紧凑密度。
- [ ] 无 emoji。
- [ ] 无强烈 AI 风。

---

## 2. 书架页

- [ ] 未使用无限下拉作为主浏览方式。
- [ ] 有智能书架筛选。
- [ ] 有当前书架内搜索。
- [ ] 有继续阅读分区。
- [ ] 有最近添加分页。
- [ ] 有系列聚合卡片。
- [ ] 有文件丢失处理入口。
- [ ] 手机端筛选栏横向滚动。
- [ ] 桌面端侧边书架固定。
- [ ] 数据查询使用分页或游标，不一次性加载全量。

---

## 3. App Shell

- [ ] 手机端底部导航。
- [ ] 平板端侧边导航。
- [ ] 桌面端侧边导航。
- [ ] TopBar 标题和副标题正确。
- [ ] 桌面端 Command Search 入口可见。
- [ ] 导入入口可见。
- [ ] 筛选入口可见。
- [ ] 页面切换动效克制。

---

## 4. 数据与架构

- [ ] 页面不直接写业务逻辑。
- [ ] 数据读写通过 Repository。
- [ ] 文件访问通过 Adapter。
- [ ] 阅读器通过 ReaderService。
- [ ] 书架通过 ShelfService。
- [ ] 搜索通过 SearchService。
- [ ] 数据库有迁移。
- [ ] shelf_preferences 已实现。
- [ ] reader_settings 已实现。
- [ ] app_settings 已实现。

---

## 5. 阅读器

- [ ] 文本阅读器支持目录。
- [ ] 文本阅读器支持搜索。
- [ ] 文本阅读器支持书签和笔记。
- [ ] 字号变化后位置稳定。
- [ ] 漫画阅读器支持双页。
- [ ] 漫画阅读器支持条漫。
- [ ] 漫画阅读器支持缩略图。
- [ ] PDF 阅读器支持目录。
- [ ] PDF 阅读器支持页码跳转。
- [ ] PDF 批注默认不写回原文件。

---

## 6. 隐私与安全

- [ ] 无登录系统。
- [ ] 无在线书源。
- [ ] 默认不上传文件。
- [ ] 默认不删除原始文件。
- [ ] 清除数据有二次确认。
- [ ] 备份默认不包含原始书籍文件，除非用户明确选择。
- [ ] 权限失效有可理解提示。

---

## 7. 性能

- [ ] 首页首屏不阻塞。
- [ ] 书架分页加载。
- [ ] 封面使用缩略图。
- [ ] 漫画页异步解码。
- [ ] PDF 逐页加载。
- [ ] 玻璃效果可降级。
- [ ] 10,000 本书可管理。
- [ ] 500MB 漫画可打开。
