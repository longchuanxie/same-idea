# 本地阅读器原型 UI 现代化改版说明

版本：V4 Modern  
目标：回应“UI 不够现代”的问题，在不丢失本地阅读器文艺克制气质的前提下，显著提升产品现代感。

---

## 1. 主要变化

### 1.1 从复古纸感转为现代工作台

上一版更接近传统纸质阅读器，风格偏温润但不够现代。  
新版调整为：

- 现代玻璃面板
- Bento 首页概览
- 更清晰的 App Shell
- 更强的信息层级
- 更利落的导航与工具栏
- 更现代的卡片、按钮、标签和搜索入口

---

## 2. 书架页优化

书架页继续避免无限下拉，采用：

- 智能书架侧栏
- 当前书架内搜索
- 固定分区
- 最近添加分页
- 系列聚合
- 查看全部入口

原则：

> 书架是管理界面，不是无尽信息流。

---

## 3. 视觉升级点

### 3.1 色彩

从米色纸感改为现代中性灰背景，配合低饱和蓝灰与暖棕强调色。  
夜读主题采用深灰蓝黑，不使用纯黑。

### 3.2 字体

UI 更偏现代无衬线，阅读页保留衬线正文。  
这样既现代，又保留阅读产品的文艺气质。

### 3.3 卡片

卡片改为轻玻璃质感和更清晰的边界，减少老式书架感。

### 3.4 首页

首页改为 Bento 式阅读工作台：

- 继续阅读大卡
- 书库统计
- 最近阅读
- 快速进入书架

### 3.5 阅读页

阅读页保持沉浸，但工具栏更现代：

- 半透明浮层
- 胶囊工具按钮
- 更干净的进度表达

---

## 4. 避免的问题

新版仍然避免：

- emoji
- 强烈 AI 风
- 荧光渐变
- 过度拟物
- 内容平台式推荐流
- 无限下拉式书架

---
